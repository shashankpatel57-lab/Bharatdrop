BharatDrop Privacy Policy

Effective date: 22 September 2026

No Data Retention: BharatDrop is designed for direct local transfer between devices. The developer does not operate a cloud transfer service for BharatDrop and does not retain transferred files or transfer history on developer-controlled servers.

What BharatDrop does

BharatDrop lets a user transfer files and folders from an Android device to a Windows PC over the user's local Wi-Fi or hotspot connection.

Files and storage

BharatDrop may request broad file access so the user can choose and transfer folders located in shared device storage. File content is served directly from the Android device to the user's PC on the local network. The developer does not receive or store those files.

Network use

BharatDrop opens a local transfer service while the user explicitly starts the app's server. The service is intended for devices on the same local network and is protected by a session PIN. BharatDrop does not require a BharatDrop cloud account.

Analytics, advertising, and tracking

BharatDrop does not include developer-operated analytics, advertising SDKs, or cross-app tracking in this release.

Data retention

No transferred file content is retained on developer-controlled infrastructure. Temporary partial files used for interrupted transfers are stored only on the user's destination PC and are used for resume.

Security

Users should run BharatDrop only on networks they trust and should stop the transfer server after use. Each session uses a temporary PIN for access.

Children

BharatDrop is a general-purpose file-transfer utility and is not specifically directed to children.
